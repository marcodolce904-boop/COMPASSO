COMPASSO for Adobe Illustrator — install
========================================
Requires Adobe Illustrator 2026 (v31) or later with Creative Cloud. Windows 10/11 or macOS.

1. Extract the WHOLE zip and quit Illustrator.
2. Double-click «Installa Compasso (Windows).bat» or «Installa Compasso (macOS).command».
   Windows SmartScreen: More info → Run anyway · macOS: right-click → Open → Open.
   They install Compasso.zxp with Adobe's own installer (UPIA). Without Creative Cloud,
   use the free ZXP Installer (https://aescripts.com/learn/zxp-installer/) and drop
   Compasso.zxp on it.
3. Open Illustrator → Window → Extensions → Compasso (recent versions: Extensions (Legacy)).
   Not there? Restart Illustrator; on Windows run «Diagnostica Compasso (Windows).bat»
   (read-only) and send the compasso-diagnostica.txt it saves on the Desktop.

Select your logo, pick a level, press DRAW GUIDES: the construction is drawn on a locked layer
«Compasso — Construction». REDRAW updates it, Clear removes it. Settings ⚙ → English / Italiano.
Uninstall with the «Disinstalla…» files. Preview release (beta).
